# Stacks Builder Rewards - Latest Information

## Overview

Based on the latest information from Talent App, the **Stacks Builder Rewards** program is designed to incentivize and reward developers building on the Stacks blockchain ecosystem.

## Latest Program: Stacks Challenge #2

The most recent campaign is **Stacks Challenge #2**, which runs as a three-week program with new challenges each week. This program rewards top builders on Stacks based on their contributions to the ecosystem.

## Evaluation Criteria

Builders are evaluated and rewarded based on:

1. **Hiro Chainhooks Usage** - Integration and use of Hiro Chainhooks in applications
2. **Smart Contract Activity** - Number of users and fees generated by deployed smart contracts
3. **GitHub Contributions** - Contributions to public repositories, especially Stacks-related projects
4. **On-Chain Activity** - Daily engagement and transactions on the Stacks blockchain

## Rewards

- **STX Tokens** - Primary reward currency
- **Leaderboard Recognition** - Daily updated leaderboards showing top builders
- **Community Recognition** - Visibility within the Stacks ecosystem

## How This Checkin App Fits

This checkin app is designed to:

1. **Track Daily Engagement** - Encourage daily interaction with Stacks applications
2. **On-Chain Verification** - All checkins are recorded on-chain, demonstrating active participation
3. **Build Streaks** - Gamification through streak tracking encourages consistent participation
4. **Community Building** - Shows total community engagement and participation

## Integration with Builder Rewards

The app contributes to builder rewards by:

- **Demonstrating Active Development** - Daily checkins show ongoing commitment
- **On-Chain Activity** - Each checkin is a transaction, contributing to on-chain metrics
- **User Engagement** - Encourages builders to stay active in the ecosystem
- **Smart Contract Usage** - Uses and promotes Stacks smart contract technology
